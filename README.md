# music-asset-pack

Asset pack for Moorhuhn Kart: Open Source Edition with the menu theme of the remake. Install it from the Asset Packs section of the Mods screen.

## Audio

`main_theme.mp3` is normalized to -16 LUFS, matching the mods' per-song music target, with decoded peaks below 0 dBFS. The original sample rate, channels and decoded duration are preserved; playback gains remain unchanged.
